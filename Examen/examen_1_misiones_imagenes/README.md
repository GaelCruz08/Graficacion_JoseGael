# Examen 1 - Misiones de Imágenes

## Descripción

En esta actividad se trabajan diferentes imágenes usando procesamiento digital con Python y OpenCV.

Cada misión aplica una operación distinta, como aclarar una imagen oscura, unir mitades, reducir ruido, separar canales de color, corregir rotación y detectar bordes.

## Objetivo

Aplicar operaciones básicas de procesamiento de imágenes para analizar, modificar y mejorar imágenes dadas como parte de una actividad tipo examen.

## Archivos

- `img/`: carpeta con las imágenes originales.
- `resultados/`: carpeta donde se guardan las imágenes procesadas.
- `misiones_imagenes.py`: código principal con las misiones.

## Misiones realizadas

1. Aclarar una imagen oscura.
2. Unir dos mitades de una imagen.
3. Reducir ruido en una imagen.
4. Separar canales de color.
5. Mejorar una imagen tipo microfilm.
6. Corregir una imagen rotada.
7. Detectar bordes en una imagen de vehículo.

## Conclusión

Esta actividad permite practicar diferentes técnicas de procesamiento de imágenes. Con OpenCV se pueden modificar imágenes, mejorar su visibilidad, reducir ruido y extraer información visual importante.
