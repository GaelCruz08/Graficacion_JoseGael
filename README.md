# Graficación - Jose Gael Cruz Aviles

Este repositorio fue creado para organizar de forma ordenada los trabajos, tareas, exámenes y proyectos realizados durante la materia de Graficación.

El contenido se encuentra separado por carpetas para facilitar su revisión y mantener una estructura clara.

## Estructura del repositorio

- `trabajos/tareas/`: prácticas y tareas realizadas durante el semestre.
- `examen/`: actividades relacionadas con exámenes o misiones especiales.
- `proyectos/`: proyectos completos o entregas más grandes de la materia.

## Organización

Cada actividad se encuentra dentro de su propia carpeta.  
Dentro de cada carpeta se incluyen los archivos de código, imágenes utilizadas, resultados generados y una breve explicación del trabajo.

## Objetivo

Mantener los trabajos de la materia organizados de forma clara, separando las actividades por tipo y tema.
